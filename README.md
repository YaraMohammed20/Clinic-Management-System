# Clinic-Management-System

A web-based system designed to organize and simplify clinic operations and management.

## About
The project aims to provide an efficient solution for managing clinic activities and improving the overall workflow.

## Main Modules
- Authentication
- Dashboard
- Doctors Management
- Patients Management
- Appointments
- Medical Records
- Billing
